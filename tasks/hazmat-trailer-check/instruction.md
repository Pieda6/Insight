Heartland Freight Lines' dispatch team checks every hazardous materials trailer before it leaves the dock. For each trailer, the team needs the exact placards it must display and a complete list of any pairs of packages that are loaded together illegally. The sole governing authority is the Hazardous Materials Regulations, 49 CFR Parts 171 to 180, as in force on October 1, 2026; no other rules, standards, guidance, or versions of the regulations apply.

The shipment data is in /app/data/trailers.json. This file contains one record for each trailer and the packages carried on that trailer. Each package record gives its UN number, shipping name, hazard class, and subsidiary hazards, together with its packing group, physical state, gross weight in pounds, packaging type, maximum capacity in liters, maximum net mass in kilograms, and, for gas receptacles, water capacity in pounds. It also identifies whether the package is a limited quantity and whether it contains residue only.

Each package record also supplies the labels the package must bear. An empty label list means that no package labels are required; it does not mean that label information is missing. The record includes the poison inhalation hazard zone and radioactive label, where applicable, as well as the explosives compatibility group and whether an explosive is an article or a substance. Other fields identify fireworks, cyanide, and acid. The loading information identifies the facility where the package was loaded and the bay it occupies. Package and trailer identifiers in the input are the identifiers to use in the result.

The carrier information is in /app/data/carrier.json. It identifies the carrier, establishes domestic highway transport, and describes the trailer layout. Each trailer has ten floor bays, numbered in order from the nose toward the doors, with all packages carried in a single tier. Every trailer is one transport vehicle. All movements are domestic and by highway only.

Treat the package records as complete and correct. The supplied package characteristics, required labels, loading facilities, and bay assignments are fixed facts for this task.

The carrier always uses the DANGEROUS placard wherever the governing regulation permits it instead of separate placards. The carrier displays only required placards and never adds optional placards. The output is a list of placard names, not a count of the physical placards mounted on the trailer.

For segregation purposes, packages in different bays count as separated in the manner required by the segregation rules. Packages sharing a bay are not separated. Two packages are adjacent if they occupy the same bay or bays immediately next to each other. Nothing is loaded above anything else. No load qualifies for the truckload exception in the segregation rules. Apart from segregation, every load satisfies every other loading requirement of Part 177.

Any cyanide and any acid identified in the data would generate hydrogen cyanide if mixed. Materials of the same class in the data cannot react dangerously with one another. None of the explosives in the data are detonators. The requested segregation findings must identify package pairs that may not remain loaded as recorded, using the actual package identifiers and positions provided for each trailer.

Write the result to /app/output/trailer_check.csv. Its first line must be exactly trailer_id,placards,segregation_violations. Include one row for every trailer, preserving the order of the trailer records in /app/data/trailers.json. A trailer still requires a row when it needs no placards, has no segregation violations, or has neither. Use its input identifier in the trailer_id column.

In the placards column, use the required placard names exactly as the regulation names them, written in capitals, such as FLAMMABLE or EXPLOSIVES 1.1. Sort the names alphabetically and separate them with semicolons. Write none if no placards are required. In the segregation_violations column, represent each violating pair in the form PK0001+PK0002, putting the smaller package identifier first. Include each pair once, sort the pairs, and separate them with semicolons. Write none if there are no violating pairs. Every output row is compared exactly.
