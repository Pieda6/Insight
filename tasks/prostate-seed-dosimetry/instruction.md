The radiation oncology physics service is checking the post-implant dosimetry of 60 patients treated with permanent prostate seed implants of iodine-125 or palladium-103. For every listed point, the service needs the total dose the point receives from the implanted seeds. The governing rules are those of the AAPM TG-43U1 protocol (Rivard et al., Update of AAPM Task Group No. 43 Report: A revised AAPM protocol for brachytherapy dose calculations, Med Phys 2004;31:633-674). No other rule or practice applies.

All of the input data is in /app/data/. The file /app/data/patients.json gives each patient's implant time. The file /app/data/batches.csv gives each seed batch's model and the source strength on the vendor's certificate, either as the air-kerma strength of each seed (U_per_seed), as the air-kerma strength of the whole batch of seeds_in_batch seeds (U_total), or as the apparent activity of each seed (mCi_apparent) with the conversion coefficient the vendor used, together with the certificate's calibration time and its UTC offset. The file /app/data/seeds.csv lists every seed found on the post-implant CT, with the positions of its two end markers in millimetres; when the physicist found that a detection repeats another seed, review names that seed. The file /app/data/points.csv gives the dose points in the same CT coordinates. The file /app/data/source_data.json holds the report's consensus data for each seed model. Implant times are local New York time (America/New_York), to the minute.

Every seed found was implanted at the implant time and stays where the CT shows it. The service's planning system uses the report's 2D formalism with the line-source geometry function for every seed, and between tabulated values it interpolates ln g_L(r) linearly in r and F(r, θ) linearly in r and in θ. It keeps every value exact and rounds only the final doses. The records are complete and correct.

Write your results to /app/output/point_doses.csv. The first line must be exactly patient_id,point_id,dose_gy and it must be followed by one row for each point, sorted by patient_id and then by point_id. The dose_gy column is the total dose in Gy the point receives from the implant time until the seeds have fully decayed, with four decimals. Doses are accepted within 0.1 percent or within 0.0005 Gy, whichever is larger, so do not add extra columns, blank lines or explanations.
